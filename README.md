## 📂 Managing your configuration

The Smart-Config-Kit provides several types of configuration files. You choose the one that matches your goals.

- Standard Profile: This file works for general web browsing. It routes common websites through your local connection while sending restricted traffic through your proxy.
- Gaming Profile: This file prioritizes low delay for gaming traffic. It keeps game servers on a direct path.
- Streaming Profile: This profile handles media services. It ensures your streaming quality stays high by routing video data through dedicated channels.

To change your profile, open the Smart-Config-Kit tool again and pick a new file from the menu. The tool updates your proxy client automatically. You never need to touch raw code or complex text files.

## 🏠 Common tasks

Users often want to update their configuration files. The Smart-Config-Kit makes this simple. Open the program once a week to check for new updates. If the software finds a newer version of your configuration, it asks to download it. Click yes to keep your settings current. 

If you encounter connection issues, follow these troubleshooting tips:

- Check your internet connection: Ensure your computer connects to your router.
- Verify your proxy client: Make sure your underlying app like v2rayN or Clash Verge stays open.
- Reset the configuration: If things stop working, select the default configuration file inside the kit and apply it again.
- Restart the app: Close both the kit and your proxy client, then turn them back on.

## 📋 Tips for better performance

Keep your proxy client software updated at all times. Developers fix bugs in these programs often. When you update the proxy client, re-select your file in Smart-Config-Kit. This ensures the configuration remains compatible with the latest software version.

Store your configuration files in a folder you can find easily. Do not move files after you link them to your proxy client. If you move a file, your proxy client may fail to load it. Keep the Smart-Config-Kit folder in your Documents area to maintain a tidy system.

## 🛡 Security and privacy

The Smart-Config-Kit runs locally on your computer. It does not send your data to external servers. It only downloads the configuration files provided in this repository. Your traffic data remains yours. We suggest you review the settings in your proxy client periodically to ensure your security rules remain active.
